# QA Automation / SDET LinkedIn Content Generator

## Objective
Search for the latest 15 trending topics related to QA Automation, Software Testing, Test Engineering, Quality Engineering, AI in Testing, and SDET practices.

For each topic:
1. Verify that it is currently trending or recently discussed by reputable sources.
2. Extract the key insight, innovation, challenge, or best practice.
3. Generate two LinkedIn posts:
   - English
   - Português (Brasil)
4. Write in a natural, human, professional style.
5. Avoid sounding like AI-generated marketing content.

## Topic Discovery Instructions
Find the latest 15 trending topics from sources such as:
- Testing conferences
- QA engineering blogs
- SDET communities
- GitHub trending testing projects
- Selenium ecosystem updates
- Playwright ecosystem updates
- Cypress ecosystem updates
- AI testing tools
- Test automation newsletters
- Engineering blogs
- LinkedIn discussions

Prioritize topics such as:
- AI-powered test automation
- Agentic testing
- Playwright updates
- Selenium updates
- Cypress updates
- API testing
- Contract testing
- Shift-left testing
- Shift-right testing
- Test observability
- Quality engineering practices
- CI/CD testing
- Mobile automation
- Performance testing
- Visual testing
- Test data management
- Self-healing automation
- LLM testing
- AI quality assurance
- Cloud testing

## Output Format

### Topic {{NUMBER}}: {{TOPIC_NAME}}

#### Summary
{{SHORT_SUMMARY}}

#### LinkedIn Post (English)
Write a post between 120 and 250 words.

Requirements:
- Human tone
- Practical insight
- Strong opening hook
- Personal/professional perspective
- End with a question to encourage engagement
- Use 3-8 relevant hashtags
- No emojis unless highly relevant

#### LinkedIn Post (Português)
Escreva uma publicação entre 120 e 250 palavras.

Requisitos:
- Tom humano e profissional
- Gancho forte no início
- Insight prático
- Perspectiva pessoal/profissional
- Finalizar com uma pergunta para gerar engajamento
- Utilizar de 3 a 8 hashtags relevantes
- Evitar excesso de emojis

## Writing Style

The posts should:
- Sound like an experienced QA Automation Engineer or SDET
- Be educational, not promotional
- Share opinions when appropriate
- Include lessons learned and real-world implications
- Avoid generic AI wording
- Avoid phrases such as:
  - "In today's fast-paced world"
  - "Game changer"
  - "Revolutionary"
  - "Leverage"
  - "Unlock the power"

## Quality Checklist
Before finalizing each post, verify:
- Topic is recent and relevant
- Writing feels human
- No repetitive structure across posts
- English version is natural
- Portuguese version is natural
- Hashtags are relevant
- Engagement question is included

## Final Deliverable
Generate content for the latest 15 trending QA Automation / SDET topics and return all posts in both languages.
